Cómo se calculan DEF, DEFside, MID, ATT y ATTside
ColumnaSuma de
DEFDefensa + Rapidez
DEFsideCreación + Técnica + Pase
MIDCreación + Rapidez + Técnica + Pase
ATTRapidez + Técnica + Anotación
ATTsideDefensa + Creación + Pase

Son sumas simples de los niveles de cada skill, sin ajustar por forma. Si a un jugador le falta alguna de las skills de la suma, la celda muestra «—». La barra de cada celda compara solo dentro de su columna.

Cómo se calcula cada posición
PosiciónFórmulaPeso
FF = 0 con «Con forma» apagado. F = Forma / 10 − 1 con «Con forma» encendido.—
Portero3·(Por+F) + 2·(Rap+F) + (Pas+F)/35,3
Defensa4·(Def+F) + 3·(Rap+F) + (Téc+F)8
Lateral(Defensa + M.Def) / 212
M.Def4·(Rap+F) + 4·(Pas+F) + 3·(Téc+F) + 3·(Def+F) + 2·(Cre+F)16
M.Of4·(Rap+F) + 4·(Pas+F) + 3·(Téc+F) + 3·(Cre+F) + 2·(Def+F)16
M.Prom(M.Def + M.Of) / 216
Delantero(Ano+F) + (Rap+F) + (Téc+F)3

El peso es la suma de los coeficientes. Por eso un M.Def llega a ~200 y un Delantero a ~41: no tiene sentido comparar posiciones entre sí. La barra de cada celda compara solo dentro de su columna.
